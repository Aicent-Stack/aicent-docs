# A page declares what it can do; an app asks who is asking | Aicent Stack

20 Oct 2026 · [Read the full article](https://blog.aicent.com/webmcp-walled-garden/) · [Chinese version](https://blog.aicent.com/zh/webmcp-walled-garden/)

In one week, two fronts opened. On 16 October the W3C Web Machine Learning Community Group published a WebMCP draft Community Group Report letting a web page declare JavaScript tools for AI agents &mdash; and its own security section concedes there is "no verification mechanism" and agents "must assume good faith." Two days earlier, a phone agent assistant in China published a list of 151 apps that refuse to be driven by its GUI agent, and the reason given was that an app cannot tell whether the operator is the phone's owner, the agent, or something hostile. Same missing layer, two fronts.
